# Certificate Template Specs

This directory holds template specifications and asset configurations for Code2Conquer Pvt. Ltd. internship completion certificates.

Format: Standard A4 Landscape (297mm x 210mm)
Visual styling:
- Code2Conquer Navy `#0A192F` / `#1E3A8A`
- Warm Gold accents `#D4AF37` / `#B45309`
- Elegant dual concentric border and corner ornaments
- Dual modes: QR-enabled verification code & Non-QR standard completion certificate
- High-resolution printable canvas

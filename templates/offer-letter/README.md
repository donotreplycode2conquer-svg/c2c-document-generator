# Offer Letter Template Specs

This directory holds template specifications and asset configurations for Code2Conquer Pvt. Ltd. internship offer letters.

Format: Standard A4 Portrait (210mm x 297mm)
Visual styling:
- Code2Conquer Navy `#0A192F` / `#1E3A8A`
- Clean professional typography
- Formal corporate letterhead with C2C monogram logo
- Standard terms, signatory block, and company footer
